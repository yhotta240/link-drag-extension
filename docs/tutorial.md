## 拡張機能のポップアップを開く

1. PCでChromeを開きます．
2. 右上の拡張機能メニューを開きます．
3. 「Link Drag」を選択します．ツールバーに固定しておくと，次回からアイコンをクリックして開けます．

現在はバージョン0.0.1の初期準備中です．ドキュメント・バージョン・情報タブを確認できます．以下の設定とドラッグ操作は実装予定です．

## 設定（実装予定）

- Link Dragを有効にする：リンクのドラッグ操作を有効・無効にします．
- アクション表示：ドラッグ中に，現在の方向に割り当てられたアクション名を表示します．
- 最小ドラッグ距離：アクションを実行するまでの移動距離です．初期値は30pxです．
- 方向別アクション：上下左右に，リンクを開く操作・URLコピー・何もしない操作を割り当てます．
- 初期値に戻す：設定を初期状態に戻します．

設定変更は自動保存し，ブラウザ再起動後も維持する予定です．

## 操作方法（実装予定）

リンクをマウスの左ボタンでドラッグし，移動した方向に応じたアクションをドロップ時に実行します．初期設定は次のとおりです．

| 方向 | アクション |
| --- | --- |
| ↑ 上 | 新しいタブで開く（背面） |
| ↓ 下 | 新しいタブで開く（前面） |
| ← 左 | URLをコピー |
| → 右 | 新しいウィンドウで開く |

Escキーでキャンセルできます．移動距離が最小距離未満の場合や，入力欄・編集可能領域にドロップした場合は実行しません．
