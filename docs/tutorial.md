## 拡張機能のポップアップを開く

1. PCでChromeを開きます．
2. 右上の拡張機能メニューを開きます．
3. 「Link Drag」を選択します．ツールバーに固定しておくと，次回からアイコンをクリックして開けます．

ポップアップ上部の「Link Drag を有効にする」で，拡張機能全体の有効・無効を切り替えます．初期状態は有効です．

## 設定

- Link Dragを有効にする：リンクのドラッグ操作を有効・無効にします．
- 操作メニューの表示：ドラッグ開始時はアイコンだけを表示します．アイコンの近くへドラッグすると，アイコンが拡大・発光し，操作名が表示されます．オフにするとメニューを表示せずに操作できます．
- メニューの表示距離：開始位置から操作の中心までの距離です．初期値は150pxで，80px以上に変更できます．
- 方向別アクション：上下左右に，リンクを開く操作・URLコピーを割り当てます．使わない方向は「割り当てなし」を選びます．
- 初期値に戻す：設定を初期状態に戻します．

設定変更は自動保存し，ブラウザ再起動後も維持します．

## 操作方法

リンクをマウスの左ボタンでドラッグすると，開始位置から上下左右150pxの位置に4つの操作アイコンが表示されます．実行したいアイコンの近くへドラッグすると操作名が表示され，そのまま離すと実行します．初期設定は次のとおりです．

| 方向 | アクション |
| --- | --- |
| ↑ 上 | 新しいタブで開く（背面） |
| ↓ 下 | 新しいタブで開く（前面） |
| ← 左 | URLをコピー |
| → 右 | 新しいウィンドウで開く |

Escキーでキャンセルできます．中央・斜め・操作の枠外で離した場合や，入力欄・編集可能領域にドロップした場合は実行しません．画面端では表示位置を内側へ調整し，小さなフレームでは表示距離を縮めて，全操作を表示します．

## 注意点

- HTTP・HTTPSのリンクが対象です．画像だけのドラッグや，選択テキストのドラッグは対象外です．
- 通常のクリックは変更しません．ブラウザ外へのドロップでは独自アクションを実行しません．
- Chromeの設定ページやChrome Web Storeなど，拡張機能を実行できないページでは動作しません．
- サイト独自のドラッグ操作がある領域では，サイト側の動作を優先する場合があります．
