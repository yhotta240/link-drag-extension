## Link Dragとは

Webページ上のリンクをドラッグする方向によって，リンクの開き方や操作を切り替えるChrome拡張機能です．

上下左右にアクションを割り当て，右クリックメニューを開かずにリンクを操作できます．画面端ではアイコンが円弧に並び，画面内で操作を選べます．

## 主な機能

- 右クリックメニューを使わず，ドラッグ方向（上下左右）でリンク操作を切り替え
- 方向ごとに好みの操作を割り当て可能
- 新しいタブ・ウィンドウで開く，URLをコピーするなどの様々な操作に対応

ポップアップの開き方，操作方法や設定は，チュートリアルを確認してください．
