## Link Dragとは

Webページ上のリンクをドラッグする方向によって，リンクの開き方や操作を切り替えるChrome拡張機能です．

上下左右にアクションを割り当て，右クリックメニューを開かずにリンクを操作できるようにします．

現在はバージョン0.0.1の初期準備中です．ドラッグ操作と方向別の設定画面は実装予定です．

## 主な機能（実装予定）

- 上下左右のドラッグ方向に応じたリンク操作
- 新しいタブ（前面・背面）・新しいウィンドウ・現在のタブでリンクを開く
- リンク先URLのコピー
- ドラッグ中にアクション名を表示
- ポップアップで方向別アクションや最小ドラッグ距離を設定
- 設定の自動保存と初期化

ポップアップの開き方，実装予定の操作方法や設定は，チュートリアルを確認してください．
